## P1 — แก้ก่อน release

### ธีมสว่าง (Theming)
- **T1** `src/components/app/expandable-rasi-wheel.tsx:135` และ `thai-chakra-chart.tsx:84` — panel ของ lightbox hard-code `bg-[#121214]`/`#111113` แต่ข้อความใช้ `--foreground` → ธีมสว่าง contrast 1.10:1 ชื่อกราฟและรายละเอียดดาวที่แตะมองไม่เห็น. แก้: ใช้ `bg-[var(--surface)]` (SVG มีจานดำของตัวเองอยู่แล้ว)
- **T2** `src/components/cms/site-announcement-banner.tsx:10`, `marketing/public-announcement-banner.tsx:16`, `src/app/(public)/page.tsx:79` — โทน WARNING ใช้ `text-amber-100` → บนพื้นสว่าง 1.02:1 ประกาศอ่านไม่ออกเลย. แก้: ใช้ token foreground + amber tint หรือแยกค่าใต้ `[data-theme=light]`
- **T3** `src/lib/theme-colors.ts:149` — `buildThemeVars` ส่ง `--primary` ดิบไปใช้ในธีมสว่างเมื่อ admin เปิด site theme: ทอง #c9a24b บน surface = 2.34:1 (CSS default ใช้ #8a6a22 ผ่านที่ 4.95). แก้: ถ้า `!darkBase` ให้ darken จน `contrastRatio(x, surface) >= 4.5` (helper มีอยู่แล้วบรรทัด 68)

### Accessibility
- **A1** `src/components/auth/auth-fields.tsx:31-38, 60-70` — input อีเมล/รหัสผ่านมีแค่ placeholder ไม่มี label (WCAG 1.3.1/4.1.2). แก้: `aria-label` หรือ `<label>`
- **A2** `src/components/app/settings-modals.tsx:12-45, 88-91, 153, 162` — `Modal` มี `role="dialog"` แต่ไม่มี accessible name, ไม่มี Escape, ไม่ย้าย focus, ไม่ trap, ไม่คืน focus; input ข้างในไม่มี label (2.1.1/2.4.3/4.1.2). แก้: ใช้ block เดียวกับ `confirm-modal.tsx:56-99`
- **A3** `src/components/app/transit-form-modal.tsx:262-276` — dialog ไม่มี focus management เลย (ไม่มี useEffect/useRef ในไฟล์) (2.1.1/2.4.3)
- **A4** `src/components/app/rasi-template-chart.tsx:155-164, 307-323` — `<svg role="img">` ครอบ `<g role="button" tabIndex=0>` ทำให้ดาวไม่ถูก expose ต่อ screen reader และบรรทัด 323 `outline: none` ไม่มี focus style (4.1.2/2.4.7). กระทบ thai-chakra-chart และ compact-rasi-wheel ด้วย. แก้: `role="group"` + `aria-label` และ ring บน `:focus-visible`
- **A5** `src/components/app/app-shell.tsx:846-853` — ทั้งแอปหลัง login ไม่มี `<main>` (1.3.1/2.4.1). แก้: เปลี่ยน wrapper div เป็น `<main>`
- **A6** `src/components/app/chat-view.tsx:2890, 2910` — ปุ่มหยุด/ส่ง `size-7` = 28px (2.5.5). แก้: `size-11 md:size-8`

### Performance
- **P1** `src/components/app/smooth-stream-markdown.tsx:123-147` + `chat-markdown.tsx:201-212` — typewriter `setShown(slice)` ทุกเฟรม → `completeMarkdown` + regex 3 รอบ + ReactMarkdown parse ทั้งเอกสารใหม่ 60–120 ครั้ง/วินาที คำตอบยาว 4,000 ตัวอักษรจะกระตุกช่วงท้าย. แก้: parse เต็มครั้งเดียวต่อ delta แล้วเผยทีละ block หรือ throttle เหลือ ~30 Hz
- **P2** `src/components/app/chat-view.tsx:404, 2383-2384` — state ของช่องพิมพ์อยู่ใน `ChatView` 2,977 บรรทัด ทุกตัวอักษร re-render message list ทั้งหมดรวม chart. แก้: ย้าย `input` ลง `Composer` ส่ง `onSubmit(text)` ขึ้นมา
- **P3** `chart-evidence-table.tsx:83`, `horoscope-chart-panel.tsx:135`, `expandable-rasi-wheel.tsx:22`, `rasi-template-chart.tsx:129`, `thai-chakra-chart.tsx:35` — ไม่มี `React.memo` และ `chat-view.tsx:2157-2159` ส่ง closure ใหม่ทุก render → SVG ทุกตัว re-render 60 ครั้ง/วินาทีตลอดการ stream. แก้: memo ทั้ง 5 + `useCallback` `prefillFromChart`

## แพทเทิร์นเชิงระบบ

1. **ธีมสว่างเป็น second-class** — โค้ดหลายจุดเขียนตอนมีแค่ธีมมืด แล้ว hard-code พื้นดำ (#121214, #111113) หรือสี amber/ทองดิบ โดยยังใช้ token ข้อความ ผลคือธีมสว่างพังเป็นจุดๆ แนวทาง: ห้าม hex บนพื้นผิวที่ข้อความใช้ token และเพิ่ม test contrast แบบ `tests/light-theme-surface-contrast.test.ts` ให้ครอบคลุม `--primary`/`--muted-2` ทั้งสองธีมและ palette จาก `buildThemeVars`
2. **Focus management ทำดีแต่ไม่ได้แชร์** — `confirm-modal`, `future-date-modal`, `expandable-rasi-wheel` ทำครบ แต่ `settings-modals`, `transit-form-modal`, `thai-chakra-chart` ไม่มีหรือมีครึ่งเดียว ควรดึงเป็น hook `useDialogFocus` ตัวเดียว
3. **Touch target ทำถูกที่เดียว** — `message-actions.tsx:182` `size-11 sm:size-8` คือแบบที่ควรใช้ทั่วทั้งแชท แต่ปุ่มส่ง/actions/chips ยังเป็น desktop size
4. **Render layer ไม่ทันชั้น network** — SSE coalesce ต่อเฟรมดีมาก แต่ทุกเฟรมไปจบที่ parse Markdown เต็ม + re-render chart ที่ไม่เปลี่ยน
