## แก้ในรอบนี้ (26 ก.ค. 2026)

| บั๊ก | แก้ |
|-----|-----|
| แอดมินอนุมัติ hardcode `PRO` → ทำลาย CREDIT_TOPUP | ใช้ `payment.packageCode`; แสดงคอลัมน์แพ็กเกจ |
| Pro ไม่หมดอายุ (`expiresAt: null`) | grant Pro ตั้ง `expiresAt = now + 30 วัน` |

| Self-approve | บล็อก `actor.id === payment.userId` |

4. VAPID keys (ถ้าใช้ web push)

4. Cron retention สลิป / ไม่มี security headers
5. FE: contrast `--muted-2` / light `--primary`, `aria-label` ช่องแชท
