## Plan คร่าวๆ สำหรับครั้งหน้า (เพื่อนอ่านแล้วทำต่อได้)

### โจทย์ที่ล็อกแล้ว (อย่าทำผิด)
- วงนอก: ชื่อราศีคงที่ เมษด้านบน เรียงทวนเข็ม (เมษ พฤษภ … มีน)
- วงใน: ชื่อภพเรือน เริ่ม **ตนุ** ที่ช่องราศีลัคนา แล้วทวนเข็มจนครบ 12
- ตัวอย่างตรวจ: ลัคนา **กันย์** → ตนุ@กันย์, กดุมภะ@ตุลย์, …, วินาศ@สิงห์
- ไม่ต้องแก้ engine คำนวณดวง — ใช้ลัคนา/ดาวจาก `ChartJson` ที่มีอยู่

### ค่าเริ่มต้นที่ยังรอลูกค้า (เปลี่ยนในไฟล์ค่าคงที่เท่านั้น)
```
HOUSE_NAMES = [
  "ตนุ", "กดุมภะ", "สหัชชะ", "พันธุ", "ปุตตะ", "อริ",
  "ปัตนิ", "มรณะ", "ศุภะ", "กัมมะ", "ลาภะ", "วินาศ"
]
FIXED_SIGNS_ON_WHEEL = true  // เมษบน ไม่หมุนทั้งวงตามลัคนา
```
ถ้าลูกค้าบอกภพ 12 เป็นพยายะ → แก้คำสุดท้ายใน array

### ขอบเขตรอบแรก (อย่าทำเกินถ้ายังไม่มีข้อมูล)
1. D1 กำเนิดอันใหญ่เท่านั้น
2. ธีมเว็บเดิม (ทองบนพื้นมืดที่มีอยู่) ไม่แกะกรอบทองลายรูป
3. วงเล็กในแชท + ดวงจร = รอบถัดไป
